# 💎 Колекція Дорогоцінних Каменів

CRUD додаток для управління колекцією дорогоцінних каменів з серверною фільтрацією та сортуванням.

## 📁 Структура проекту

```
цц/
├── public/              # Клієнтська частина
│   ├── css/
│   │   └── styles.css   # Стилі з градієнтами
│   ├── js/
│   │   └── app.js       # JavaScript логіка
│   └── index.html       # HTML сторінка
├── src/                 # Серверна частина
│   └── server.js        # Express сервер
├── package.json
└── README.md
```

## 🚀 Запуск проекту

1. Встановіть залежності:
```bash
npm install
```

2. Запустіть сервер:
```bash
npm start
```

3. Відкрийте браузер: `http://localhost:3000`

## ✨ Функціонал

- ➕ Додавання нових каменів
- ✏️ Редагування існуючих
- 🗑️ Видалення каменів
- 🔍 Пошук через сервер
- 📊 Сортування за різними параметрами
- 💰 Підрахунок загальної вартості колекції

## 🎨 Особливості дизайну

- Градієнтний фон (фіолетові тони)
- Градієнтні кнопки з ефектами hover
- Анімації при наведенні на картки
